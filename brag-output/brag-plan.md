# /brag — Terrafunder

**What it is:** a Spigot/Bukkit plugin for Minecraft 1.8 that adds a SkyDefender-style game mode.
**For:** Minecraft server admins who want to host an event for many teams.
**What sets it apart:** one team defends a castle, nine attacking teams fight each other to steal its emerald block and place it on bedrock. Days, PvP, the world border and random loot chests all run on their own.
**Hook:** "9 équipes. 1 château. 1 bloc d'émeraude."
**Share caption:** one emerald block, one castle to defend, nine teams to steal it.

**Angle:** a game trailer for a game mode. Everything on screen uses the plugin's own text: the § color codes from the chat, the FastBoard sidebar ("Terra**Funder**", Jour, Defenseur, Attaquant, Bordure), the config values (10 teams, PvP day 3, castle attack day 4, border 2000 → 500) and the logo `img/Terra.png`.
**Tone:** cinematic with a playful edge, in French like the plugin.
**Visual identity:** a night-sky gradient, emerald #55FF55 / #00AA00, the defenders' aqua #55FFFF, the Minecraft chat palette, the Pixelify Sans and Silkscreen pixel fonts, and pixel-art blocks.
**Music:** an original chiptune loop in A minor at 120 BPM (square-wave lead, triangle bass, kick and hats), with the sound effects in the same key.
